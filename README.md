### ⚡ What is this Node?
First Sovereign Node for Web4 `.teos` domains, built in Alexandria.

- **/core:** Rust resolver that queries Solana Blockchain for .teos NFT owners
- **/gateway:** Node.js server that makes .teos work on any browser
- **/auction:** Anchor smart contract for sovereign domain auctions (doctor.teos, etc)
- **/browser:** TEOS Browser MVP - First Sovereign Web4 Browser (Native .teos Resolver + Built-in Wallet)
