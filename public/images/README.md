# TEOS Images

Brand and marketing assets for the TEOS Web4 `.teos` name experience.

- `teos-banner.webp` — main site banner (960x540)
- `teos-gate.webp` — .teos gate / hero illustration (1600x1067)
- `teos-dig-certificate.webp` — on-chain "dig" certificate asset (1600x1067)

Static files in this directory are served from the `/images/` URL path.
